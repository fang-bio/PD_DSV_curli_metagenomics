# Supplementary tables

This folder contains the supplementary tables associated with the Parkinson’s disease metagenomic meta-analysis.

The file `supplementary_tables.xlsx` includes cohort-level information, sample-level quality-control summaries, statistical model outputs, ecological interaction analyses, and functional pathway results supporting the main and supplementary figures.

## File

- `supplementary_tables.xlsx`  
  Excel workbook containing Supplementary Tables 1–13.

## Table descriptions

| Table | Description |
|---|---|
| Supplementary Table 1 | Summary of publicly available fecal metagenomic datasets included in this study. |
| Supplementary Table 2 | Sample-level information after quality control and host-read removal. |
| Supplementary Table 3 | PERMANOVA assessment of disease status, cohort, geographic region, and sequencing platform effects on global microbiome structure. |
| Supplementary Table 4 | Targeted MaAsLin3 analysis of Desulfovibrio, Escherichia coli, and bacterial curli-gene abundance in Parkinson’s disease. |
| Supplementary Table 5 | Spearman correlation analysis of ecological coupling among Desulfovibrio, Escherichia coli, and bacterial curli genes. |
| Supplementary Table 6 | Mixed-effects logistic regression models assessing continuous interaction effects between Desulfovibrio and curli-gene abundance. |
| Supplementary Table 7 | Predicted Parkinson’s disease probabilities from mixed-effects logistic regression models across standardized microbial abundance gradients. |
| Supplementary Table 8 | Odds ratios for Parkinson’s disease across categorical Desulfovibrio–curli exposure groups. |
| Supplementary Table 9 | PERMANOVA assessment of functional microbiome variation associated with cohort effects and Desulfovibrio–curli interaction terms. |
| Supplementary Table 10 | Group-mean standardized abundances of pathway-level features across Desulfovibrio–curli exposure groups. |
| Supplementary Table 11 | Significant pathway-level features associated with the Desulfovibrio × curli interaction. |
| Supplementary Table 12 | Significant pathway-level features with positive Desulfovibrio × curli interaction coefficients. |
| Supplementary Table 13 | Significant pathway-level features with negative Desulfovibrio × curli interaction coefficients. |

## Notes

These supplementary tables were generated from the analysis scripts provided in the repository. They are intended to support reproducibility of the statistical analyses and figure-level results, including targeted microbial feature analyses, ecological interaction models, predicted-risk landscapes, and functional pathway profiling.
